Pre-recorded Chichewa voice prompts go here, one MP3 per key, e.g.

  home.mp3          "Mukufuna mmisiri wanji? ..." (home screen)
  signup_trade.mp3  "Mumagwira ntchito yanji? ..." (provider signup, step: trade)
  signup_name.mp3   step: name
  signup_area.mp3   step: area
  signup_payout.mp3 step: payout number
  signup_service.mp3 step: first service
  book.mp3          booking screen
  pay.mp3           payment screen

Keep each under 30 seconds, mono, 32 kbps, so the APK stays small.
The ListenButton plays assets/audio/<key>.mp3 and shows "audio coming soon" if the file is missing.
